## 🚀 Featured Work

<table>
<tr>
<td width="50%">

### 🥑 GuavaCam — Industrial CV System
Real-time guava **detection · counting · sizing · grading** from CCTV on a 3-lane packing-house conveyor.

- YOLO segmentation + IoU tracking
- Checkerboard calibration → **ray-plane pixel-to-mm**
- **XGBoost** weight estimation (A3 core-10 features)
- Multi-threaded runtime, async DB writer w/ dead-letter, OTA updates with health-gate + auto-rollback

`Python` `PyTorch` `YOLO` `OpenCV` `XGBoost` `MySQL`

</td>
<td width="50%">

### 🪖 SmartCampus Vision — Traffic Analytics
Real-time helmet-violation detection & tracking on an event-driven pipeline.

- **YOLOv8 + ByteTrack**, end-to-end ML workflow
- **Kafka → Spark Streaming** event pipeline
- Star-schema data mart in PostgreSQL + Grafana dashboards

`PyTorch` `YOLOv8` `ByteTrack` `Kafka` `Spark` `PostgreSQL`

</td>
</tr>
